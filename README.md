
# Bạch Mai Hospital Management System - Manual Testing

## 1. Project Overview
Dự án kiểm thử thủ công hệ thống quản lý khám chữa bệnh tại Khoa Khám chữa bệnh theo yêu cầu - Bệnh viện Bạch Mai.

- **Project Type:** Personal Project / Graduation Project
- **Role:** Manual Tester
- **Testing Type:** Functional Testing, UI Testing
- **Test Management Tools:** Jira, Zephyr, Google Sheets

## 2. Testing Objectives
- Đánh giá hoạt động của các chức năng trong phạm vi kiểm thử.
- Xác minh kết quả thực tế so với kết quả mong đợi.
- Phát hiện, ghi nhận và báo cáo lỗi.
- Tổng hợp kết quả thực thi test case.

## 3. Testing Scope

Các chức năng được kiểm thử:

- Đăng nhập
- Quản lý bệnh nhân
- Quản lý thuốc
- Quản lý giấy khám bệnh
- Quản lý phiếu cận lâm sàng
- Quản lý lịch làm việc bác sĩ

## 4. My Responsibilities

- Phân tích chức năng và thiết kế test case.
- Thực thi test case và ghi nhận kết quả.
- Kiểm thử chức năng và giao diện website.
- Ghi nhận và theo dõi lỗi phát hiện.
- Quản lý test case bằng Zephyr và tổng hợp dữ liệu bằng Google Sheets.
- Sử dụng Jira để theo dõi công việc và lỗi kiểm thử.
